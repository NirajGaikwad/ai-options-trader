QUICK START (5 MINUTES)
================================================================================

OPTION 1: Docker Compose (Recommended)

1. Clone and setup:
   cd /c/Trade
   cp .env.example .env

2. Start services:
   docker-compose up -d

3. Wait 30 seconds for services to start

4. Verify:
   curl http://localhost:8000/health

5. Access:
   - API Docs: http://localhost:8000/api/docs
   - Frontend: http://localhost:3000
   - Grafana: http://localhost:3001 (admin/admin)
   - Prometheus: http://localhost:9090

OPTION 2: Local Setup (Python)

1. Create virtual environment:
   python3.11 -m venv venv
   source venv/bin/activate

2. Install dependencies:
   pip install -r requirements.txt

3. Start PostgreSQL and Redis:
   brew services start postgresql redis

4. Initialize database:
   python scripts/init_db.py

5. Run application:
   cd backend
   python main.py

6. Access API Docs:
   http://localhost:8000/api/docs

EMERGENCY PROCEDURES
================================================================================

STOP ALL TRADING IMMEDIATELY:
  curl -X POST http://localhost:8000/api/trading/emergency-stop

CHECK HEALTH:
  curl http://localhost:8000/health

VIEW LOGS FOR ERRORS:
  docker-compose logs -f backend

RESTART SYSTEM:
  docker-compose restart backend

FULL RESTART (with data preserved):
  docker-compose down
  docker-compose up -d

FACTORY RESET (DELETE DATA):
  docker-compose down -v

================================================================================
TROUBLESHOOTING
================================================================================

System won't start:
  - Check Docker: docker --version
  - View logs: docker-compose logs backend
  - Check ports: lsof -i :8000

API not responding:
  - Check service: docker-compose ps
  - Test health: curl http://localhost:8000/health
  - View logs: docker-compose logs -f backend

Database error:
  - Check PostgreSQL: psql -U postgres
  - Verify credentials in .env
  - Check database exists

Port in use:
  - Find process: lsof -i :8000
  - Kill it: kill -9 <PID>
  - Or change port in .env

For more help:
  - See SETUP.md → Troubleshooting
  - Check logs: docker-compose logs -f
  - Review health endpoint: http://localhost:8000/health/detailed
