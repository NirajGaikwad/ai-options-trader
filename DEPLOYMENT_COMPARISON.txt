WHAT HAPPENS AUTOMATICALLY

On Every Push:
  → Code quality checks (lint, type, security)
  → Docker image built
  → Image pushed to GitHub Container Registry
  → Tests run
  → Status reported

Every Day at 08:00 IST:

3. Wait 2-3 minutes for setup
4. In terminal:
   python setup.py
   ./start-local.sh
5. Open: http://localhost:8000/api/docs

DONE! Platform running in cloud! ✅

================================================================================
OPTIONAL: SLACK NOTIFICATIONS
================================================================================

Get alerts about market events (5 minutes to setup):

1. Create Slack workspace or use existing
2. Create Incoming Webhook:
   Go to api.slack.com/apps
   Create New App
   Enable Incoming Webhooks
   Copy webhook URL
3. Add to GitHub Secrets:
   Repository → Settings → Secrets
   New secret
   Name: SLACK_WEBHOOK
   Value: (paste URL)

Done! Get alerts like:
  🟡 "Market opening soon"
  🟢 "Market is open"
  🟠 "Market closing soon"
  🔴 "Market is closed"
